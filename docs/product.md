# 제품: 쏙쏙

## 무엇을 하는가

어려운 글을 AI 로 **쉬운 정보**로 바꿔 주는 서비스다.

## 누가 쓰는가

- 고령층 (큰글씨 모드의 주 대상)
- 발달장애인
- 외국인 노동자

글을 읽기 어려운 사람이 쓰는 앱이므로 변환 결과뿐 아니라 앱 화면 자체도 쉬워야 한다.

## UX 원칙

**아직 비어 있다.** Figma 디자인을 기준으로 채운다.
그 전까지 화면 · 문구 · 크기 · 색은 Figma 디자인을 따르고, 추측으로 규칙을 만들지 않는다.

## 화면 (라우트 기준)

| 경로             | 화면                      |
| ---------------- | ------------------------- |
| `/`              | 첫 화면                   |
| `/login`         | 로그인                    |
| `/documents`     | 내 문서 목록              |
| `/documents/$id` | 문서 상세                 |
| `/s/$token`      | 토큰으로 여는 문서 페이지 |

## 확인 필요

정해지면 이 목록에서 지우고 위 본문에 반영한다.

- Figma 파일 링크와, 그 디자인에서 뽑은 UX 원칙
- 입력 방식 (텍스트 붙여넣기, 파일 업로드, 사진 촬영 등)
- `/s/$token` 의 용도 (공유 링크인지, 로그인 없이 볼 수 있는지)
- 다국어 지원 여부
- 로그인 · 인증 방식
